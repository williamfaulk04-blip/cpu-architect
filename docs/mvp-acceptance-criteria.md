# GPU Architect MVP Acceptance Criteria

## Playable MVP Criteria

The playable MVP is accepted when all of the following criteria are met:

- All 15 approved components appear across the three stages.
- Only one socket is active at a time.
- Correct and incorrect choices produce the approved feedback.
- Score, first-attempt bonus, penalties, stage bonuses, accuracy, and failure threshold work.
- Progress is based on installed pieces.
- Stage explanations and final results appear.
- Explore GPU and Rebuild GPU work.
- Desktop, tablet, and mobile layouts remain usable.
- Keyboard and touch alternatives are available.
- Sound can be muted and reduced motion is respected.
- A clean static build runs from the GitHub Pages repository subpath.

## Definition of Done

Every implementation card must meet the following requirements before it can be marked Done:

- Meets the card acceptance criteria.
- Contains no CPU-specific labels unless intentionally referenced.
- Has keyboard and pointer behavior checked.
- Has responsive behavior checked at desktop and mobile widths.
- Introduces no console errors or broken asset paths.
- Is reviewed by at least one teammate before moving to Done.
